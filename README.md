# Facebook Ads Performance Dashboard

Simple Power BI dashboard for exploring Facebook ad campaign performance.

## Files

- `data/KAG_conversion_data.csv` — source dataset
- `FacebookAds.pbip` — editable Power BI Project
- `FacebookAds.Report/` — report pages and visuals
- `FacebookAds.SemanticModel/` — model, DAX measures, and CSV query
- `FacebookAds.pbix` — packaged Power BI report

## Open

1. Open `FacebookAds.pbix` to view the report.
2. Open `FacebookAds.pbip` to edit the report in Power BI Desktop.
3. Refresh the model if Power BI asks for the CSV location.

## Dashboard

The report includes campaign filters, KPI cards, spend and conversion charts, ad-effectiveness comparisons, and detailed tables. DAX measures cover spend, impressions, clicks, enquiries, approved conversions, CTR, CPC, CPM, approval rate, and conversion cost.
